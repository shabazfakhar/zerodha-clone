Zerodha Clone

A full-stack stock trading platform inspired by the official Zerodha web application.
This project replicates core trading dashboard functionalities including authentication, holdings management, portfolio UI, and responsive landing pages.

🚀 Live Features

User Authentication (Login / Signup)
JWT-based Protected Routes
Responsive Landing Website
Dashboard UI
Holdings & Portfolio Section
Watchlist UI
Buy Window UI
React Router Navigation
MongoDB Integration
REST API Backend
Modular Component Structure

⚙️ Installation & Setup

1️⃣ Clone Repository
git clone https://github.com/shabazfakhar/zerodha-clone.git

2️⃣ Install Dependencies
Frontend
cd frontend
npm install
Dashboard
cd dashboard
npm install
Backend
cd backend
npm install

▶️ Run Project
Start Frontend
cd frontend
npm start
Start Dashboard
cd dashboard
npm start
Start Backend
cd backend
npm start


🔐 Environment Variables

Create a .env file inside backend folder:

MONGO_URL=your_mongodb_connection
JWT_SECRET=your_secret_key
PORT=3002
